Tableloom is a desktop workspace for designing, testing, and printing tabletop games.

- Design cards, tokens, boards, tiles, player aids, and packaging with editable templates.
- Manage component data, artwork, rules, and localized text in one project.
- Check layouts, compare revisions, and export print sheets or component artwork.
- Test manually with drag and drop, piles, discard areas, counters, and saved setups.
- Receive a notification when a newer GitHub release is available.

**Windows downloads**

Choose **Setup.exe** to install Tableloom, or **Portable.exe** to run it without installing. Both builds are unsigned. `SHA256SUMS.txt` contains the download checksums.

Six original starters are included. Third-party game examples are distributed separately.

Private release checks use a signed-in GitHub CLI or a token saved in the app’s update preferences. Updates open on GitHub for manual download and installation.
